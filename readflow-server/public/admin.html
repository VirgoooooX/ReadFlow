    媒体处理

    %

    数值越低体积越小。推荐：70–80（日常省流），80–90（更清晰），100（接近不压缩）。

    启用图片转码

    关闭后 /api/image 默认走 raw，不触发 WebP 转码与压缩参数。

    RSS 抓取策略

    全局默认的 RSS 自动刷新间隔。单位秒，单个源如配置了独立刷新频率则以源配置为准。推荐：300–1800（5–30 分钟）。

    留空则使用默认刷新间隔（秒）。示例：*/15 * * * *（每15分钟）、0 * * * *（每小时）、0 8 * * *（每天8点）。

    每次抓取单个订阅源时最多解析的条目数量，用于防止某些源一次返回上万条导致内存和 CPU 暴涨。推荐：20–100；0 表示不限制（不推荐）。

    云同步接口单页允许返回的最大文章数量。客户端即使请求更大的 limit 也会被限制在该值以内。推荐：200–500；过大可能导致内存峰值过高。

    抓取 RSS 源或文章全文时的网络超时时间，单位毫秒。超过该时间请求会被中止并记录为失败。推荐：10000–20000。

    云同步接口在客户端未指定 limit 时使用的默认分页大小。推荐：50–200（首次追平历史不宜过大）。

    库存治理

    定期清理早于该天数的旧文章，按发布时间计算。推荐：30–365；0 表示永久保留（数据库会持续增大）。

    为每个订阅源最多保留的最新文章数量。超出部分会从最旧的开始批量删除。推荐：500–5000；0 表示不限制。

    后台文章清理任务的执行间隔，单位小时。包括按保留天数和每源库存上限的自动删除。推荐：6–24。

    安全设置

    修改后下次登录生效。默认密码: admin
